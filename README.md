# ♟️ Schach Arena

Schach im Browser – gegen Bots, die zu deiner ELO passen, oder online gegen Freunde.

## ▶️ Jetzt spielen

**https://tillwassenhoven1-glitch.github.io/schach/**

Keine Installation, kein Konto nötig – läuft auf Handy, iPad und PC. 🎮

## So funktioniert's

* 📈 Du startest mit **800 ELO** – wie bei chess.com
* 🤖 Wähle einen Bot – die grün markierten passen zu deinem Niveau
* 🏆 Gewinnst du, steigt deine ELO – verlierst du, sinkt sie
* 💪 Je besser du wirst, desto stärkere Bots werden dir empfohlen
* 🌐 Oder erstelle einen Raum und spiele mit einem Freund

## Features

* 🤖 10 Bots von 🐣 Küken Kalle (250) bis 👑 König X (2400)
* ⭐ „Empfohlen“-Markierung für den Bot, der am besten zu dir passt
* 📊 Vor jeder Partie siehst du, wie viel ELO du gewinnen oder verlieren kannst
* 🌐 Online-Multiplayer: Raum erstellen → 4-stelligen Code an Freund schicken → spielen
* 🤝 Remis anbieten, 🏳 Aufgeben und 🔁 Revanche (mit Farbwechsel)
* 👥 Lokaler Modus: 2 Spieler an einem Gerät
* 💡 Tipp-Button gegen Bots
* 🖱️ Figuren anklicken oder ziehen – mögliche Züge werden angezeigt
* ♟️ Alle Regeln: Rochade, en passant, Umwandlung, Patt, 50-Züge-Regel, Stellungswiederholung
* 📈 Profil mit ELO-Verlauf, Statistik und letzten Partien
* 🔊 Sounds für Züge, Schlagen, Schach und Matt

## Hinweise

* 💾 Deine ELO wird im Browser gespeichert (pro Gerät)
* 🌐 Online-Partien laufen direkt von Browser zu Browser – in sehr strengen Netzwerken (z. B. Schul-WLAN) kann die Verbindung manchmal nicht klappen
